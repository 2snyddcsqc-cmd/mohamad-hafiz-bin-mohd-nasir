# Architecture Decision Records (ADRs)

This folder contains Architecture Decision Records for the **mohamad hafiz ** initiative.

## What is an ADR?

An ADR is a short document that captures an **important architectural decision**,
the **context** that prompted it, the **options** considered, and the **consequences**
of the chosen option.

## Naming Convention

```
NNNN-short-descriptive-title.md
```

- `NNNN` is a zero-padded sequential number (0001, 0002, …)
- Use lowercase kebab-case for the title

## Status Lifecycle

```
Draft → Proposed → Accepted → Deprecated → Superseded by NNNN
```
